# 入荷チェック（v1.2.0）

店舗間移動伝票の商品コードと、商品タグのバーコードを照合する入荷確認用Webアプリです。
iPhone（Safari）・Android（Chrome）で動作し、「ホーム画面に追加」でアプリとして使えます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| index.html | 画面 |
| style.css | デザイン |
| app.js | 動作（伝票の文字認識・連続読み取り・照合） |
| vendor/zxing-0.21.3.min.js | バーコード読み取りライブラリ（ZXing, Apache-2.0） |
| vendor/tesseract/ | 伝票の文字認識（Tesseract.js 5.1.1, Apache-2.0）と英数字の認識データ |
| manifest.webmanifest | ホーム画面アイコン・アプリ名の設定 |
| sw.js | オフライン起動用（更新時は中の CACHE 番号と index.html の ?v= を上げる） |
| icons/ | アプリアイコン |

## 使い方（概要）

1. 「伝票を撮影」→ 端末内で商品コードを読み取り、リストを作成（「要確認」は写真を見て修正）
2. 伝票の行数と件数が合っているか確認
3. 「連続読み取りを開始」→ バーコードを枠に合わせると自動で照合（緑=OK／黄=読取済み／赤=伝票にない）
4. 「照合結果を表示」で未確認・リスト外を確認

## 注意

- カメラを使うため、https のURL（GitHub Pages など）で開く必要があります。
- データは各端末の中だけに保存され、外部には送信されません。文字認識も端末内で行います。
- 文字認識のデータ（約11MB）は初回の伝票撮影時に読み込み、2回目以降は端末に保存されたものを使います。
